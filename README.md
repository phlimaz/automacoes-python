# ⚙️ Automações em Python

Repositório dedicado a scripts, rotinas e ferramentas de automação desenvolvidas em Python.

---

## 🎯 Objetivo
Reduzir o tempo gasto em tarefas operacionais e repetitivas através de scripts práticos, seguros e eficientes.

---

## 📂 Estrutura do Projeto
- `main.py`: Script de exemplo que analisa diretórios e gera estatísticas automáticas de arquivos.
- `.gitignore`: Configuração para ignorar arquivos temporários, logs e arquivos do Excel.

---

## 🚀 Como Executar

1. Certifique-se de ter o Python instalado.
2. No terminal, execute:
   ```bash
   python main.py
   ```
